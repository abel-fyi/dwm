# Local patches

This tree tracks upstream dwm and carries these local changes:

- alpha bar rendering with configurable bar and border opacity;
- per-tag layouts, master counts, factors, and bar visibility;
- full gaps with per-monitor gap state;
- personal colors, sizing, key bindings, and status script;
- `Mod+p` application launcher prompt;
- `Mod+e` searchable Unicode emoji picker with clipboard output.

The original patch files are retained under `patches/` for reference. The
committed source is authoritative because the patches have been integrated and
adjusted for the current upstream tree.
